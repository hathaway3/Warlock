# Warlock Code of Conduct

The Warlock project is committed to providing an environment where all participants can learn and reach objectives with respect and dignity. We aim to be a welcoming and helpful community for developers of all backgrounds.

## 🤝 Our Guidelines
1.  **Be Respectful:** Treat all participants with respect. Professional disagreement is fine; personal attacks are not.
2.  **Stay On Topic:** Keep discussions focused on the project's technical scope.
3.  **Assume Good Faith:** Always assume that others are contributing with good intentions, even if their work or comments are flawed.

## 🚫 What is Unacceptable
We are not tolerant of:
*   Harassment or abusive behavior.
*   Discriminatory comments.
*   Personal attacks or name-calling.

If you see behavior that violates this Code of Conduct, please report it to a project maintainer using the reporting mechanism specified in the project's issue tracker.
