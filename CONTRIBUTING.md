# Contributing to Warlock

We welcome contributions to Warlock! Whether it's finding a bug, improving documentation, or adding a new feature, your help is greatly appreciated.

## 🐛 Reporting Bugs
If you encounter a bug, please follow these steps:
1.  Use the reproduction steps clearly.
2.  Include the operating system and version used.
3.  If possible, include logs or relevant API request/response pairs.
4.  Report bugs on the Issue Tracker, referencing the relevant component (e.g., "API Service Module").

## 💡 Suggestions & Features
If you have an idea for a new feature:
1.  Open a new issue titled "Feature Request: [Feature Name]".
2.  Provide a detailed proposal, outlining the *why*, the *what*, and the *expected outcome*.

## 💻 Developer Setup
1. Clone the repository.
2. Follow the steps in the `CONTRIBUTING.md` guide.
3. Run `npm install` in both the root and the `frontend` directory.
4. Run `npm run test` to ensure all tests pass before submitting a PR.

## ✅ Pull Request Process
1.  Ensure your branch name follows the format: `fix/issue-number-short-description` or `feat/issue-number-short-description`.
2.  The PR body must reference the associated ticket number and summarize the changes.
3.  The code must pass all linting checks and tests.
4.  A detailed description of the feature/fix must be provided.
