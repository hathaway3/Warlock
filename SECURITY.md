# Security Policy

Warlock is committed to maintaining the highest level of security for all users and their data. All security vulnerabilities must be reported responsibly and privately.

## 🚨 Responsible Disclosure Policy
If you discover any potential security vulnerability in Warlock, please **do not** disclose it publicly.

Instead, please report it immediately by:
1.  Creating a private issue in the repository's issue tracker.
2.  In the title, state "Security Vulnerability Report".
3.  Provide enough information for us to reproduce the issue, but keep any potentially sensitive data generic (e.g., use sample users instead of real credentials).

## 🔍 Our Commitment
Our team commits to:
1.  **Acknowledgement:** Acknowledging receipt of the report within 24 hours.
2.  **Remediation:** Developing a patch or mitigation strategy.
3.  **Resolution:** Reaching out to the reporter with a fix, and coordinating the public disclosure (e.g., a CVE) once the patch is deployed.

**Do not wait for us to find the issue. If you find it, report it responsibly.**
